# UI/UX Pro Skill & Design System Guidelines

This skill provides comprehensive guidelines for designing award-winning, luxury user interfaces with superior user experience and optimal conversion rates.

## Core Design Principles

1. **Luxury Glassmorphism & Depth Layers**
   - Use multi-layer frosted glass (`bg-white/50 backdrop-blur-xl border border-white/40 shadow-sm`).
   - Employ subtle glowing background orbs (`mix-blend-multiply blur-[120px]`) in complementary brand colors (`#006097`, cyan, slate, amber).
   - Use inset box shadows and gradient borders (`border-white/60`) for modern tactile glass depth.

2. **Typography & Persian RTL Excellence**
   - Ensure clean line heights (`leading-relaxed` or `leading-tight`) and font weighting hierarchy (`font-black`, `font-extrabold`, `font-bold`, `font-medium`).
   - Use standard Persian numbers or well-formatted numerals with badge highlights.
   - Use clear contrast ratios meeting WCAG AAA / AA accessibility guidelines.

3. **High-Conversion CTA & Status Cues**
   - Provide primary action buttons with tactile click states (`active:scale-98 transition-all hover:scale-[1.02]`).
   - Combine action triggers with urgency/social proof indicators (e.g. live pulsing capacity badges, trust seals, verified student counts).

4. **Micro-Interactions & Fluid Motion**
   - Add hover lift effects (`hover:-translate-y-1 hover:shadow-lg transition-all duration-300`).
   - Use subtle shimmer on logos or key highlights (`animate-pulse`, `animate-ping` for active status).
   - Keep interactions smooth and non-intrusive.
